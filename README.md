## Live site / deployment

This repository contains a static portfolio site (HTML/CSS/JS). To publish on GitHub Pages:

1. Push your changes to GitHub (main branch).
2. Open the repository on GitHub → Settings → Pages.
3. Under "Build and deployment" choose `Deploy from a branch`, then select `main` and `/ (root)` as the folder.
4. Save — your site will be published at `https://<your-username>.github.io/<repo>` shortly.

Optional: Use a GitHub Actions workflow or the `gh-pages` branch for more advanced deployment automation.
